# Notices

This repository is a clean text-frontend workspace split from a larger private
Nepali TTS research tree.

Code is released under the MIT license unless a file states otherwise.

The files in `data/frontend/` include project-authored tables and derived
pronunciation data. Some entries are derived from Google's open Nepali language
resources released with:

- Keshan Sodimana, Knot Pipatsrisawat, Linne Ha, Martin Jansche, Oddur
  Kjartansson, Pasindu De Silva, and Supheakmungkol Sarin. "A Step-by-Step
  Process for Building TTS Voices Using Open Source Data and Framework for
  Bangla, Javanese, Khmer, Nepali, Sinhala, and Sundanese." SLTU 2018.
- Google language-resources Nepali lexicon and phonology resources.

Before publishing this repository publicly, verify every copied/derived data
file has its required upstream notice and license text included.
